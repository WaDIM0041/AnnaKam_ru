# ANNA KAM: сайт и чат-бот

Обновлено из основной локальной working-hosting/site 21.10.2026.
Публичный код бота: bot/ и bot-api/. Ключей, базы и приватного конфига здесь нет.
PHP 8.1+, cURL и PDO SQLite нужны для ИИ. GitHub Pages PHP не исполняет.
Приватная папка anna-bot-private должна находиться вне DocumentRoot всех сайтов.
Без приватной настройки PHP включает сценарную демонстрацию браузера.
Публикация в GitHub сама по себе не подтверждает загрузку на annakam.ru.
Локальный лимит пилота: 20 попыток обращения к провайдеру в сутки UTC.
На хостинге необходимо отдельно проверить расширения, TLS, приватное хранение,
правила данных и плановую очистку. Не загружать локальные ключи в Git.
