## Перед переносом

1. Откройте отдельную рабочую копию проекта на диске D. Возьмите файлы из коммита ветки `codex/annakam-seo-hosting-20261127`. Зафиксируйте SHA коммита. Проверенные образцы для предпросмотра находятся на [GitHub Pages](https://wadim0041.github.io/AnnaKam_ru/). Файлы для хостинга находятся в этой ветке и используют корневые адреса annakam.ru.
2. Через штатный доступ к хостингу определите фактический корень annakam.ru. Скачайте шесть текущих файлов из списка и сохраните резервную копию вне публичной папки с сохранением структуры. Сверьте скачанное с базовыми хешами. Отдельно сравните публичные HTTP-ответы. Если есть различия, сначала разберите изменения и объедините их с правкой, сохранив свежую работу.
3. Таблица использует SHA-256 от текста UTF-8. Перед расчётом замените CRLF на LF и удалите пробельные символы в конце файла. Исходная версия соответствует коммиту `b8bb8a4`. Все семь публичных адресов, включая sitemap.xml, были сверены с этой версией перед передачей. Карта содержит 21 адрес.

## Что перенести

Заменить шесть перечисленных HTML-файлов по тем же относительным путям. Загрузить файлы во временные имена и по возможности заменить каждый файл атомарным переименованием. Обновить кэш этих URL, если хостинг его использует. Загружать только файлы из таблицы. В репозитории два файла в `_source/` сохраняют изменения для будущих сборок. `sitemap.xml`, `robots.txt`, серверные настройки и остальные файлы в этом выпуске загрузки не требуют.

## Приёмка после переноса

- Для шести URL подтвердить HTTP 200, канонический адрес на annakam.ru, один H1 и ожидаемые title и description. Сравнить тело ответа с ожидаемым хешем с учётом нормализации выше. При включённом кэше проверить актуальный ответ после его сброса.
- На главной проверить широкое предложение о разработке любых подходящих для команды сайтов и цифровых проектов. Открыть каталог, этапы запуска и сопровождение. Проверить связку «Строительство» → «АртЭлитБалкон» → опубликованное демо калькулятора. На мобильной ширине проверить переход к контактам.
- Проверить, что опубликованный sitemap по-прежнему содержит 21 адрес annakam.ru. Google уже принял карту, Яндекс поставил семь URL в очередь перед выпуском. После подтверждения публикации проверить состояния в обоих кабинетах и запросить переобход обновлённых URL по необходимости. Через 7 и 21 день замерить индекс, показы и клики по целевым коммерческим запросам.
- При регрессии восстановить затронутые файлы из резервной копии, очистить их кэш и проверить исходные ответы. Если причину отклонения нельзя устранить сразу, остановить выпуск и зафиксировать проблемный URL, способ восстановления и проверенный статус.
- В отчёте Создателю указать SHA, время выпуска, результаты HTTP и проверки переходов. Приложить ссылки на фактически проверенные страницы annakam.ru. Отдельно указать подтверждённый результат и то, что осталось проверить в поиске.
