# Орбиты проектов ANNA KAM

Блок на главной заменяет прежнюю композицию из трёх окон. В коллекции — все 11 решений из `_source/products.json` и существующий авторский проект «Через время к звёздам». Изображения и адреса демонстраций берутся из каталога. Авторский проект обозначен отдельно.

Возможности: три объёмные орбиты, независимое покачивание карточек, вращение перетаскиванием, инерция, пауза по наведению и при работе клавиатурой, ручная пауза. Горизонтальный жест на телефоне вращает коллекцию; вертикальный оставляет прокрутку страницы. Стрелки вращают коллекцию, Tab и Enter выбирают и открывают проекты. При системном ограничении движения автовращение отключено. Без JavaScript доступна обычная сетка ссылок.

## Сборка

Из `_source`: `npm run build:orbits` обновляет только блок и его ресурсы на текущей главной, сохраняя независимые изменения страницы и помощника. Обычный `npm run build` тоже включает блок, но пересобирает весь сайт из исходников. Ресурсы имеют хеш в имени, чтобы опубликованная страница не получала старую версию из кеша.

## Проверка

`npm run test:orbits`: соответствие всем записям каталога, наличие изображений, повторная сборка без изменений, сохранение посторонней разметки, экранирование содержимого и отказ при неверной точке вставки.

Также проверено в Chrome: загрузка 12 изображений, ссылки, пауза, стрелки, перетаскивание без случайного открытия, переход по Enter, границы карточек на ширинах 390/360/320, ограничение движения и отображение без JavaScript. Проверка размеров выполнена с отключёнными вступительными анимациями остального сайта.

## Публикация

Ветка `main` хранит исходники и главную для annakam.ru. GitHub Pages использует отдельную ветку `gh-pages` и пути с префиксом `/AnnaKam_ru/`. Для обновления блока в этой ветке переносятся только главная и два новых ресурса, с сохранением остальных её файлов.

Изменения сервера, базы данных и других сайтов в пакет не входят.
